# eXp Agent Tools and Resources Inventory

Use this reference when an agent says, “I didn’t know eXp had a tool for that,” “where do I find X?”, or “what should I use for this task?” Verify current access inside Passport/Okta, My eXp, eXp Knowledge Base, Workplace, eXp World, eXp University, and state/broker resources because tools, names, and eligibility change.

## Discovery rule

Before recommending outside software, ask: “Is there an eXp-provided tool, training, support desk, or discount for this?” Then check the categories below.

| Resource | What it helps with | Where to look / access | Coaching caveats |
|---|---|---|---|

## Tool-selection coaching examples

| Agent asks | Skill should guide them to |
|---|---|
| “Where do I log in for everything?” | My eXp + Passport/Okta + Workplace + eXp World/eXpert Care. |
| “How do I get help?” | eXp Knowledge Base first, then eXp World/eXpert Care or support ticket. |
| “How do I get leads?” | CRM readiness first, then sphere/open houses/content, then Making It Rain if follow-up system is ready. |
| “What CRM should I use?” | First check eXp CRM of Choice: BoldTrail, Cloze, Lofty. Standard use may be included/no-additional-fee through the eXp tech package; choose based on business style and verify add-ons/IDX/country rules before paying for outside CRM. |
| “How do I make flyers or business cards?” | Marketing Center for templates, Marketing Store/BuildASign for print, broker approval for compliance. |
| “How do I handle seller cash-offer options?” | ExpressOffers training/certification and broker-approved seller-options conversation. |
| “How do I work luxury?” | eXp Luxury eligibility, Academy, branding/listing tools. |
| “How do I learn contracts in my market?” | Country/state/province training events, local broker/country team, mentor, SkySlope/mock file or local transaction tool. |
| “How do I submit a transaction file?” | SkySlope training + transaction support + broker checklist. |
| “How do I get referrals?” | eXp Global Referral Platform/Revenos resources plus broker/referral-agreement rules. |

## Pitfall

Many eXp resources are gated or renamed over time. The coaching skill should avoid pretending every agent has the same dashboard. Use wording such as: “Search Passport/My eXp/eXp Knowledge Base for [tool name], or ask eXpert Care to route you.”
